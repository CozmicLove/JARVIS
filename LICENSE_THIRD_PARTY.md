# Third-party visual source

NOVA Control Center V2 adapts visual presentation code from
[Dix01/JARVIS](https://github.com/Dix01/JARVIS) at commit
`7b8a33becbf4e2ed2f7bbe858f7a4445748d03fa`.

Adapted source includes the SVG orb renderer, atmosphere, corner frame,
top/bottom status rails, visual stylesheet, Tailwind theme, and web build setup
under `src/ui/control_center_v2_web/`. NOVA's data and application behavior
remain supplied by its existing Python runtime.
